# Generate company department names

Generate company department names

## Usage

``` r
fkr_department(n)
```

## Arguments

- n:

  Number of values to generate. A single non-negative whole number.

## Value

A character vector of length `n`.

## Examples

``` r
fkr_department(5)
#> [1] "Operations"               "Research and Development"
#> [3] "Administration"           "Marketing"               
#> [5] "Finance and Accounting"  
```
