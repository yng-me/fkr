# Generate job titles

Generate job titles

## Usage

``` r
fkr_job_title(n)
```

## Arguments

- n:

  Number of values to generate. A single non-negative whole number.

## Value

A character vector of length `n`.

## Examples

``` r
fkr_job_title(5)
#> [1] "Municipal Administrator" "Marketing Associate"    
#> [3] "Software Developer"      "Municipal Administrator"
#> [5] "Virtual Assistant"      
```
