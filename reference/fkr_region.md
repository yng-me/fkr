# Generate Philippine regions

Generate Philippine regions

## Usage

``` r
fkr_region(n)
```

## Arguments

- n:

  Number of values to generate. A single non-negative whole number.

## Value

A character vector of length `n`, drawn from the Philippines' 17
administrative regions.

## Examples

``` r
fkr_region(5)
#> [1] "Cordillera Administrative Region (CAR)"
#> [2] "Region V (Bicol Region)"               
#> [3] "Region VIII (Eastern Visayas)"         
#> [4] "Region II (Cagayan Valley)"            
#> [5] "Region XI (Davao Region)"              
```
