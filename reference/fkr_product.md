# Generate product names

Draws from a curated list of products typical of Philippine retail and
sari-sari (small variety) stores.

## Usage

``` r
fkr_product(n)
```

## Arguments

- n:

  Number of values to generate. A single non-negative whole number.

## Value

A character vector of length `n`.

## Examples

``` r
fkr_product(5)
#> [1] "Coconut Vinegar"    "Canned Corned Beef" "Salted Duck Eggs"  
#> [4] "Salted Duck Eggs"   "Buko Pie"          
```
